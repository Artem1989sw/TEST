# Тест на рівень англійської мови (A1–B2)

Тест із 50 запитань для визначення рівня англійської — від A1 до B2.
Питання йдуть послідовно від найпростіших до найскладніших і щоразу
вибираються випадково з більшого банку питань, тому кожне проходження
відрізняється.

## Файли

- **`index.html`** — сам тест. Повністю самодостатній файл (без
  залежностей), відкривається в будь-якому браузері.
- **`server.py`** — невеликий локальний сервер на Python. Роздає
  `index.html` і автоматично зберігає результат кожного проходження в
  папку `log/` (окремий JSON на спробу + зведений `results.csv`).
- **`start-test.bat`** — запускає `server.py` і відкриває тест у
  браузері одним подвійним кліком (для Windows).

## Як запустити

### Варіант 1 — просто відкрити тест (без збереження результатів)

Відкрийте `index.html` подвійним кліком у будь-якому браузері. Тест
повністю працює, але результати нікуди не зберігаються.

### Варіант 2 — з автоматичним збереженням результатів (рекомендовано)

1. Переконайтесь, що встановлений [Python 3](https://www.python.org/).
2. Запустіть **`start-test.bat`** подвійним кліком.
3. Відкриється консольне вікно сервера і браузер із тестом.
4. У консольному вікні буде показано два посилання:
   - `http://localhost:8000/` — для вас, на цьому комп'ютері;
   - `http://<IP-адреса>:8000/` — для інших людей у тій самій
     мережі (Wi-Fi/роутер). Просто надішліть їм це посилання —
     нічого завантажувати не потрібно, тест відкриється як звичайний
     сайт.
5. Кожен пройдений тест автоматично зберігається в папку `log/`:
   - `result_ДАТА_ЧАС.json` — повні дані однієї спроби;
   - `results.csv` — зведена таблиця всіх спроб (відкривається в Excel).

Щоб зупинити сервер — просто закрийте його консольне вікно.

> **Важливо:** цей спосіб працює лише в межах однієї локальної мережі.
> Люди поза цією мережею (наприклад, з іншого міста) відкрити
> `http://<IP-адреса>:8000/` не зможуть.

## Логіка визначення рівня

Рівень вважається "засвоєним", якщо точність відповідей на ньому ≥60%.
Підсумковий рівень — це найвищий рівень, для якого засвоєні й усі
попередні (нижчі) рівні теж. Наприклад, високий відсоток на B2 не
зарахується, якщо провалено A2.
