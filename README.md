# Тест на рівень англійської мови (A1–B2)

Тест із 40 запитань (по 10 на рівень) для визначення рівня англійської —
від A1 до B2. Рівні йдуть послідовно від найпростіших до найскладніших.

У `index.html` є банк на 200 питань (по 50 на кожен рівень). Щоразу
для кожного рівня випадково береться 10 питань, порядок питань і
варіантів відповіді перемішується. Питання, які вже показували в цьому
браузері, не повторюються, доки не закінчаться невидані (це 5 проходжень
поспіль), після чого цикл починається заново. Усередині одного тесту
питання ніколи не повторюються.

> Історія «вже бачених» питань зберігається в `localStorage` браузера,
> тому вона окрема для кожного пристрою/браузера. Очистка даних сайту
> скидає її.

Кількість питань на рівень змінюється константою `LEVEL_COUNTS` у
`index.html`.

## Файли

- **`index.html`** — сам тест. Повністю самодостатній файл (без
  залежностей), відкривається в будь-якому браузері.
- **`server.py`** — невеликий локальний сервер на Python. Роздає
  `index.html` і автоматично зберігає результат кожного проходження в
  папку `log/` (окремий JSON на спробу + зведений `results.csv`).
- **`start-test.bat`** — запускає `server.py` і відкриває тест у
  браузері одним подвійним кліком (для Windows).

## Як запустити

### Варіант 1 — просто відкрити тест (без збереження результатів)

Відкрийте `index.html` подвійним кліком у будь-якому браузері. Тест
повністю працює, але результати нікуди не зберігаються.

### Варіант 2 — з автоматичним збереженням результатів (рекомендовано)

1. Переконайтесь, що встановлений [Python 3](https://www.python.org/).
2. Запустіть **`start-test.bat`** подвійним кліком.
3. Відкриється консольне вікно сервера і браузер із тестом.
4. У консольному вікні буде показано два посилання:
   - `http://localhost:8000/` — для вас, на цьому комп'ютері;
   - `http://<IP-адреса>:8000/` — для інших людей у тій самій
     мережі (Wi-Fi/роутер). Просто надішліть їм це посилання —
     нічого завантажувати не потрібно, тест відкриється як звичайний
     сайт.
5. Кожен пройдений тест автоматично зберігається в папку `log/`:
   - `result_ДАТА_ЧАС.json` — повні дані однієї спроби;
   - `results.csv` — зведена таблиця всіх спроб (відкривається в Excel).

Щоб зупинити сервер — просто закрийте його консольне вікно.

> **Важливо:** без тунелю (див. нижче) тест працює лише в межах однієї
> локальної мережі. Люди поза цією мережею (наприклад, з іншого міста)
> відкрити `http://<IP-адреса>:8000/` не зможуть.

### Варіант 3 — доступ з будь-якої мережі (тунель Cloudflare)

1. Покладіть `cloudflared.exe` у цю папку (завантажити можна з
   [релізів cloudflared](https://github.com/cloudflare/cloudflared/releases),
   файл `cloudflared-windows-amd64.exe`, перейменувавши його на
   `cloudflared.exe`). Акаунт не потрібен.
2. Запустіть `start-test.bat`. За кілька секунд у консольному вікні
   з'явиться рядок `ПУБЛІЧНЕ ПОСИЛАННЯ` на кшталт
   `https://щось-там.trycloudflare.com`. Воно також лежить у
   `public-url.txt`.
3. Надішліть це посилання будь-кому — воно відкриється з будь-якої мережі.
   Результати падають у `log/` на цьому комп'ютері, як і раніше.

Обмеження: комп'ютер має бути ввімкнений, а консольне вікно сервера —
відкрите, поки люди проходять тест. Посилання змінюється при кожному
запуску.

Безпека: через посилання доступна лише сторінка тесту. Папка `log/`,
`server.py` і `.git` недоступні (404), а сервер зберігає лише результати
суворо очікуваного формату.

### Варіант 4 — у хмарі: GitHub Pages + Google Таблиця (комп'ютер не потрібен)

Тест відкривається за постійним посиланням
`https://artem1989sw.github.io/TEST/` з будь-якої мережі, а кожен
результат додається рядком у вашу Google Таблицю (і, за бажанням,
приходить вам листом).

1. Створіть нову Google Таблицю.
2. У ній: **Розширення → Apps Script**. Замініть увесь код вмістом файлу
   `cloud/apps-script.gs`. Якщо листи не потрібні, поставте
   `NOTIFY_BY_EMAIL = false`.
3. **Розгорнути → Нове розгортання → тип «Веб-застосунок»**:
   «Виконувати як» — **Я**, «Хто має доступ» — **Усі**. Дозвольте доступ
   до таблиці й пошти, коли Google попросить. Скопіюйте URL, що
   закінчується на `/exec`.
4. Вставте цей URL у `index.html`: `const RESULTS_ENDPOINT = '...';`
5. Закомітьте й запуште зміни в `main`; за хвилину GitHub Pages оновить
   сторінку.

Після зміни коду в Apps Script треба робити **нове розгортання** (або
«Керувати розгортаннями → редагувати → нова версія»), інакше працюватиме
стара версія.

На стартовому екрані є необов'язкове поле «Ваше ім'я». Воно потрапляє в
останню колонку таблиці («Ім'я»), у лист і в локальний `results.csv`.

> URL приймача видно в коді сторінки, тож теоретично будь-хто може
> надіслати в таблицю фальшиві результати. Скрипт приймає лише дані
> суворо очікуваного формату, але не відрізняє справжню людину від
> підробки. Для звичайного тестування цього достатньо.

## Логіка визначення рівня

Рівень вважається "засвоєним", якщо точність відповідей на ньому ≥60%.
Підсумковий рівень — це найвищий рівень, для якого засвоєні й усі
попередні (нижчі) рівні теж. Наприклад, високий відсоток на B2 не
зарахується, якщо провалено A2.
